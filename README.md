# Library Management App

## Description

A JavaScript application that allows users to manage a collection of books. Users can add books, view their collections, update reading statuses, and remove books from the library.

## Features

* Add new books to the library.
* Remove books from the collection.
* Update a book's reading status.
* Find a specific book.
* View the book collection.
* Track which books have been read.
* Display a message when the library is empty.
* Validate user inputs.
* Local storage

## Technologies Used

* HTML5
* CSS3
* JavaScript
